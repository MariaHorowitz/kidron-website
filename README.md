# Kidron Capital website

This repo holds the content of kidron-capital.com. The layout comes from the Metanoia site template; see `netlify.toml`.

- **Text and settings:** `site.json`. Edit the text there.
- **Pictures:** `images/`.
- **Extra pages** served as they are: `static/`.

Every push to `main` rebuilds the site on Netlify. If a build fails, the previous version stays live.
